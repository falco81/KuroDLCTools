# Pre-generated schema pack

These 144 schemas were auto-generated by `generate_schemas.py` from a
sample corpus of 1543 TBL files extracted from:

- Trails in the Sky 1st Chapter (PAC, 237 files)
- Trails through Daybreak (P3A, 179 files)
- Trails through Daybreak II (P3A, 473 files)
- Trails beyond the Horizon (P3A, 411 files)
- Ys X Nordics (P3A, 243 files)

## Coverage

After dropping these into the plugin's `schemas/headers/`, the plugin
recognizes 280 (existing) + 144 (these) = **424 unique sections** —
covering virtually every section that appears in the corpus above.

## Quality caveat

These schemas use generic field names (`field0`, `field1`, ...) and
have type accuracy around 40-50%. They are intended as a **starting
point**, not a final answer:

- The grid will show typed columns instead of raw passthrough — much
  more useful than nothing.
- Saves still round-trip correctly even if some types are slightly
  wrong (uint vs int, 2×uint vs ulong).
- You should refine field names and types as you work with each
  section.

## How to use

Copy all `*.json` from this folder into:

```
<plugin install dir>/schemas/headers/
```

Restart Total Commander. Sections previously shown as raw bytes will
now appear as typed grids.

## Differences from the official KuroTools schemas

Generated schemas use the platform key `"GENERATED"` (instead of
`FALCOM_PC`, `NISA_PC`, `CLE_PC`, `FALCOM_PS4`, `FALCOM_SWITCH`).
The plugin matches by entry length first and platform name second,
so `GENERATED` will match any platform whose entry length matches.

If a section ever gets a real schema added with a matching platform
key, the real schema will take precedence.
